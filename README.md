This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo run:ios
   ```

## Rules

- Tap on grid to start the game session
- The game session lasts until you lose
- Tap the right bottom button to view the leaderboard with all game sessions from best to worst
- Game sessions are stored in database on device, it restores on the leaderboard appearance
